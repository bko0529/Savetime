# Handoff: 세이브타임 병원 웹·관리자 웹 스타일 개선

## 개요
bko0529/Savetime 의 `web/` (Next.js 16 · Tailwind v4 · shadcn/Base UI) 병원 웹과 관리자 웹의 **화면 구조·문구·동작은 그대로 두고 스타일만** 바꾸는 작업이다.
사용 환경은 응급실 데스크 PC (1280~1920px)이다.

## 디자인 파일에 대해
이 폴더의 `.dc.html` 파일은 **HTML로 만든 디자인 참고용 시안**이다. 저장소에 그대로 넣지 말고, 기존 `.tsx` 컴포넌트의 Tailwind 클래스를 고쳐서 똑같이 보이게 만든다.
- `Savetime Demo.dc.html`: 시연 시작 화면 (병원 웹 / 관리자 웹 선택)
- `SavetimeWeb.dc.html`: 모든 화면 (위쪽 어두운 막대는 시안 전용 화면 전환기이므로 구현하지 않는다)
- `Savetime Flow.dc.html`: 화면 흐름 한눈에 보기

브라우저로 열면 바로 보인다 (같은 폴더의 support.js 필요).

## 정확도
High-fidelity. 색·크기·간격을 아래 값대로 맞춘다. 기존 파일의 문구, 접근성(role, aria-*), 테스트 셀렉터, 상태 로직은 바꾸지 않는다. 시안의 환자·병원 데이터는 예시이다.

## 꼭 지킬 것 (CLAUDE.md)
- 브랜치 이름: `web/S?-UI-style-refresh` 형식, main 직접 커밋 금지, PR로 올린다
- 구급대 소속을 표시하지 않는다. 새 라이브러리는 추가하지 않는다
- `npm test` (web) 통과를 확인한다. 테스트가 텍스트·role 로 찾으므로 문구는 그대로 유지한다
