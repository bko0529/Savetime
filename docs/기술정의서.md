- 기준: 요구사항분석서 v1.1 (COR·INR·SER·PER·QUR·DAR) · 설계 v0.2 (`docs/design-v0.2/`)
- 작성: 2026-10-08 · 수정: 2026-10-10 · 담당: 백강욱
- 상태: **v0.2부터 모든 항목 확정** (T-01~T-06 결정 완료). 바꾸려면 단톡에 먼저 말하고 10. 바뀐 기록에 남겨요

> 이 문서는 "무엇을, 어떤 버전으로, 왜 쓰는지"를 정하는 **자재 목록표**예요. 여기 없는 라이브러리를 새로 쓰려면 단톡에 먼저 말하고 이 문서에 한 줄 추가해요.

## 1. 전체 구성

```
 [구급대원 앱]  React Native (Android 10+ · iOS 16+)
      │  REST (HTTPS)  +  Socket.IO /app (WSS)
      ▼
 [서버]  Node.js 24 · Express 5 · Socket.IO 4 ──── PostgreSQL 16
      ▲          │  외부: 공공 응급의료 API · 카카오 길찾기·주소 · FCM
      │  REST + Socket.IO /hospital · /admin
 [병원 웹 + 관리자 웹]  Next.js 16 (한 프로젝트, /hospital · /admin)

 배포: AWS Lightsail 서울 1대 = Caddy(HTTPS) → 웹(Next.js) · 서버(/api, /socket.io) · PostgreSQL
       도메인 1개(같은 사이트) → 병원 PC 쿠키(SameSite=Strict)가 그대로 동작
```

- 상태를 바꾸는 일은 **REST**, 서버가 먼저 알려주는 일만 **웹소켓** (실시간 통신 설계 v0.2)
- 세 파트 모두 **TypeScript** → `shared/events.ts`(이벤트 타입)를 같이 씀
- 백엔드·DB는 구급대원 서비스 전용, 일반인 앱과 공유하지 않음 (COR-005)
