## 1. 전체 구성

```
 [구급대원 앱]  React Native (Android 10+ · iOS 16+)
      │  REST (HTTPS)  +  Socket.IO /app (WSS)
      ▼
 [로드밸런서]  HTTPS · 도메인 1개 · 상태 점검(/health)
      ├─▶ [앱 서버 1]  Caddy → 웹(Next.js 16) + 서버(Node.js 24 · Express 5 · Socket.IO 4)
      └─▶ [앱 서버 2]  (같은 구성)
               │
               ├─▶ Redis 7  : 서버 간 실시간 연결 공유 · 작업 큐(타이머·수집) · 요청 제한
               ├─▶ PostgreSQL 16 (1대 + 매일 백업)
               └─▶ 객체 저장소 : 공무원증 사진(암호화)
      ▲  REST + Socket.IO /hospital · /admin
 [병원 웹 + 관리자 웹]  Next.js 16 (한 프로젝트, /hospital · /admin)

 외부: 공공 응급의료 API(전국 17개 시·도) · 카카오 길찾기·주소 · FCM
 도메인 1개(같은 사이트) → 병원 PC 쿠키(SameSite=Strict)가 그대로 동작
```

- 상태를 바꾸는 일은 **REST**, 서버가 먼저 알려주는 일만 **웹소켓** (실시간 통신 설계 v0.2)
- 세 파트 모두 **TypeScript** → `shared/events.ts`(이벤트 타입)를 같이 씀
- 백엔드·DB는 구급대원 서비스 전용, 일반인 앱과 공유하지 않음 (COR-005)
- 병상 데이터는 **전국 17개 시·도**를 3분마다 수집 (D-104, T-07)
- 앱 서버는 **2대**, 서버끼리 공유할 것은 모두 **Redis 또는 DB**에 둠 → 어느 서버가 받아도 결과가 같음 (D-105, T-08)
